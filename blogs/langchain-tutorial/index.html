LangChain Tutorial: Building AI Applications with Large Language Models

LangChain has emerged as one of the most powerful frameworks for building applications with Large Language Models (LLMs). Whether you're creating chatbots, document analyzers, or AI agents, LangChain provides the tools and abstractions you need. In this tutorial, we'll explore the core concepts and build practical applications.

What is LangChain?

LangChain is a framework designed to simplify the creation of applications using large language models. It provides modular components for working with LLMs, including prompt templates, memory systems, chains, and agents. Think of it as the "Swiss Army knife" for LLM application development.

Core Concepts

🔗 Chains

Combine multiple components into a single, cohesive workflow

📝 Prompts

Template-based prompt engineering for consistent outputs

🧠 Memory

Maintain context across multiple interactions

🤖 Agents

Autonomous systems that can use tools and make decisions

Getting Started

First, install LangChain and set up your environment:

# Install LangChain
pip install langchain langchain-openai python-dotenv

# Create .env file for API keys
echo "OPENAI_API_KEY=your-api-key-here" > .env

Basic LLM Interaction

from langchain_openai import ChatOpenAI
from langchain.schema import HumanMessage, SystemMessage
from dotenv import load_dotenv

load_dotenv()

# Initialize the LLM
llm = ChatOpenAI(model="gpt-4", temperature=0.7)

# Simple message
messages = [
    SystemMessage(content="You are a helpful AI assistant."),
    HumanMessage(content="Explain quantum computing in simple terms.")
]

response = llm.invoke(messages)
print(response.content)

Prompt Templates

Prompt templates allow you to create reusable, parameterized prompts:

from langchain.prompts import ChatPromptTemplate

# Create a template
template = ChatPromptTemplate.from_messages([
    ("system", "You are an expert in {domain}. Provide detailed explanations."),
    ("human", "{question}")
])

# Use the template
prompt = template.format_messages(
    domain="artificial intelligence",
    question="What are transformers in deep learning?"
)

response = llm.invoke(prompt)
print(response.content)

Building Chains

Chains connect multiple components together. Here's how to build a simple chain:

from langchain.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from langchain.schema.output_parser import StrOutputParser

# Define the prompt
prompt = PromptTemplate.from_template(
    "Write a short poem about {topic} in the style of {style}."
)

# Create the chain using LCEL (LangChain Expression Language)
chain = prompt | ChatOpenAI() | StrOutputParser()

# Run the chain
result = chain.invoke({
    "topic": "artificial intelligence",
    "style": "Shakespeare"
})
print(result)

Adding Memory

Memory allows your application to remember previous interactions:

from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain
from langchain_openai import ChatOpenAI

# Initialize memory
memory = ConversationBufferMemory()

# Create conversation chain
conversation = ConversationChain(
    llm=ChatOpenAI(temperature=0.7),
    memory=memory,
    verbose=True
)

# Have a conversation
response1 = conversation.predict(input="Hi, my name is Renish!")
print(response1)

response2 = conversation.predict(input="What's my name?")
print(response2)  # Will remember "Renish"
1
User Input - Receive question or command from user
2
Memory Retrieval - Fetch relevant context from memory
3
Prompt Formation - Combine template, context, and input
4
LLM Processing - Send to language model for generation
5
Response & Update - Return response and update memory

Working with Documents (RAG)

Retrieval Augmented Generation (RAG) lets you build applications that answer questions based on your own documents:

from langchain.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Chroma
from langchain.chains import RetrievalQA

# Load document
loader = PyPDFLoader("document.pdf")
documents = loader.load()

# Split into chunks
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200
)
chunks = text_splitter.split_documents(documents)

# Create embeddings and vector store
embeddings = OpenAIEmbeddings()
vectorstore = Chroma.from_documents(chunks, embeddings)

# Create QA chain
qa_chain = RetrievalQA.from_chain_type(
    llm=ChatOpenAI(),
    chain_type="stuff",
    retriever=vectorstore.as_retriever()
)

# Ask questions about your document
answer = qa_chain.invoke("What is the main topic of this document?")
print(answer)
"RAG combines the power of retrieval systems with generative models, allowing LLMs to access and reason over your specific data without fine-tuning."

Building Agents

Agents can use tools and make decisions autonomously:

from langchain.agents import create_openai_tools_agent, AgentExecutor
from langchain.tools import Tool
from langchain import hub

# Define custom tools
def search_web(query: str) -> str:
    """Simulated web search"""
    return f"Search results for: {query}"

def calculate(expression: str) -> str:
    """Calculate mathematical expressions"""
    return str(eval(expression))

tools = [
    Tool(name="search", func=search_web, description="Search the web"),
    Tool(name="calculator", func=calculate, description="Perform calculations")
]

# Create agent
prompt = hub.pull("hwchase17/openai-tools-agent")
agent = create_openai_tools_agent(ChatOpenAI(), tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# Run agent
result = agent_executor.invoke({
    "input": "What is 25 * 4 and then search for Python tutorials"
})
print(result)

Best Practices

  1. Use Environment Variables: Never hardcode API keys in your code
  2. Implement Error Handling: LLM calls can fail; always handle exceptions
  3. Monitor Costs: Track token usage to manage API costs
  4. Test Prompts: Iterate on prompts to get optimal results
  5. Use Caching: Cache LLM responses when possible to reduce costs
  6. Version Control: Keep track of prompt versions and chain configurations
